# VideoActionAgent — 视频内容整理与问答

一个在 Windows 本机运行的视频助手开发版本：给出 B 站公开视频链接和本次要求，读取允许使用的内容，生成可保存、可继续提问、可修改和下载的成果。

这份仓库用于保存当前源代码及第三方代码来源。**它不是已验证的开箱安装包。** 当前部署曾跨多个本地工作目录开发，部分导入、启动和历史数据接入仍带机器路径。个人运行数据、账号、模型密钥、浏览器会话与模型权重均不随仓库发布。不能只克隆仓库便声称已完成安装。

## 已经实现并在本机观察的能力

- 当前正常网页的新链接从声音作本地转写，保存可复用的来源材料；独立字幕读取模块存在，但尚未接为网页的“字幕优先、识别备援”。获取失败不能当成没有字幕或空内容。
- 根据本次要求整理笔记、提纲、操作步骤或回答问题。行动计划只在任务需要时生成；不把单一示例定为全部用户需求。
- 复用已有来源，继续提问或修改已保存成果，不必每次重新下载、转写。局部文字可直接编辑；需要模型时单独授权并保留旧版本。
- 重复粘贴链接时，可从当前所有者已保存的同视频/分 P 材料中选择匹配识别；必须重新核对当前音轨 CID、字节哈希和时长。不是仅凭链接命中就把旧材料冒充新来源。
- 按需利用保存帧、画面文字识别及视觉模型补充局部画面语义。已经观察的具体帧不等于看懂整部视频。
- 可选的受控图文解释：关系适合时使用示意图或同一对象的状态面板。允许零图；图必须说明来源性质，不能把模型生成图冒充原视频截图。
- 保存、读取、版本修订和导出；图文成果的下载包包含正文及已绑定的本地图像/参数文件。
- 本机会话、文字/图像发送许可、来源与版本绑定、取消及迟到结果保护。模型或外部操作结果未知时不会自动重发。

## 代码目录

| 目录 | 内容 |
|---|---|
| `MAIN/` | Python 运行时、来源处理、提供方、CLI、数据迁移与测试；不是当前网页的唯一入口。 |
| `APP/` | 当前用途网页的本地 API、任务策略、生成与局部修订、可选图文执行器。 |
| `VIS/` | 原生 BiliNote 适配、保存材料、帧及画面处理。 |
| `DOWN/bridge_contract.py` | 本地适配的文件与记录合同。 |
| `DOWN/BiliNote/` | 固定来源的 BiliNote 后端及当前使用的 React 阅读前端。 |
| `SOURCE-MANIFEST.json` | 本次归集文件及 SHA-256；用于核对源码快照，不是内容质量证书。 |

当前前端入口为 `purpose.html`，使用 `vite.purpose.config.ts` 与本地 `/api/bridge` 接口。它不是双击静态 HTML 就能连接全部能力的页面。

本版本的有限交付与验收见 `MAIN/docs/version-delivery-contract.md`，默认处理和修复决策见 `MAIN/docs/default-processing.md`。它们区分讲者主张、解释、独立核验和建议；没有相应能力的必要部分保持缺口，不把部分交付称为原任务全部完成。

## 环境与安装边界

原部署使用 Python 3.12、Node.js/Vite、Windows PowerShell，以及按路径选用的声音/画面工具。`MAIN/pyproject.toml` 和锁文件描述主运行时，BiliNote 原后端依赖清单位于 `DOWN/BiliNote/backend/requirements.txt`；后者包含原项目的广泛依赖，**并非已经精简验证的最小安装集合**。前端依赖以所附 `package.json` 与相应锁文件为准；旧 npm 锁曾存在与 manifest 不一致的问题，不应混用包管理器假设可复现。

当前主要待移植项：

1. APP/VIS 及本机启动器中的绝对目录，需要显式配置或改为本仓布局。
2. APP 的旧来源 seed/adopt 接线引用了不随包发布的个人开发数据；应改为可选导入或使用明确的合成材料，不能通过复制私人 runtime 解决。
3. 可选 Codex 写作者固定了经核验的客户端、模型和独立本机认证；可执行文件与认证不包含在仓库中。不能把订阅额度当作通用免费 API，也不静默改用别的账户或提供方。
4. 新视频声音识别、抽帧、OCR 等需要额外工具/模型及资源；它们不是读取已有文字成果的必需步骤。钥匙、模型路径和授权由使用者在自己机器配置。

因此本次没有提供未经干净环境验证的“一键安装”命令。既有本机启动脚本保留用于理解实际部署；请先审其路径，**不要直接把未知目录或服务当成已配置完成**。

## 质量、时长与成本

保存成功表示文件与任务链路已完成相应步骤，不能证明模型内容全对，也不能证明用户已经理解。语音识别、人名、参数、代码与画面推断仍可能有误；资料中没有的事实应保留未知，重要内容需要核对。

已观察的材料复用任务中，短答可以一次调用完成；整篇内容与复杂修订仍可能等待数分钟。首次处理视频还要加来源获取和声音/画面处理。短输出仍可能需要完整输入，局部修改也不保证低输入词元。没有统一三分半保证，也没有根据本机订阅用量推算通用 API 现金账单。

默认额外全文编辑层因实测增加开销且没有改善内容而停用。图是可选表达，测试通过不证明配图会提升理解；用户净省时、长期使用意愿和普遍优于通用 AI 尚未得到验证。

## 验证范围

本轮针对图文执行器、来源/版本边界、局部增改删、真实 API 生命周期和写作者选择做过一次稳定的串行定点检查；前端有就地投影/精确内容链接的检查及用途构建。真实保存与下载也留有核对证据。

这不等于所有历史测试、所有视频和所有提供方都经过发布认证。历史前端的整库 lint/类型检查仍有债务；局部通过不能表述为全库干净。源码归集与凭据模式扫描也不是完整安全审计。
