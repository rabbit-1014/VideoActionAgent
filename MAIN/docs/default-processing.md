# 默认处理与修复

2026-10-28。配合 `version-delivery-contract.md` 使用；本文说明执行选择，不代表这些选择已经通过运行验收。

| 观察到的需要或失败 | 默认处理 | 结束条件 |
| --- | --- | --- |
| 只问一个明确问题或要短摘要 | 直接给所需结果，不先写整篇笔记、行动计划或导图 | 所需事实与必要条件回答完 |
| 要理解概念或观点联系 | 从结论、对象与关系组织；比较短文、例子、表格、局部图的实际作用 | 关键联系与适用条件清楚，不堆重复解释 |
| 要应用、拟稿或计划 | 提供本次可用交付，分开来源内容与新增建议 | 必要前提、结果、依赖和检查方式明确；不擅加训练日程 |
| 要核验当前事实或真实效果 | 先检查是否有独立证据和已授权的相应工具；没有则保留必需缺口 | 已有部分可用，未核验的部分没有伪装为事实 |
| 必需信息只在未取得的画面或声音中 | 只在已有许可和能力内补相应材料；否则说明具体缺项 | 缺项已补，或诚实部分交付/拒绝 |
| 有材料但稿件漏掉或误写关键意思 | 根据原来源局部修改，复查原要求与相关限定 | 修复确实生效，未损失其他必要内容；不默认重跑来源 |
| 事实无误但表达不适合用途 | 调整组织或局部表达工具，保留来源和任务 | 用户无需重做委托的组织；不因为可配图就配图 |
| 缺实际文件或执行能力 | 明确能力缺口；仅在用户接受时交付等效替代 | 不把大纲当文件或把计划当执行 |
| 已有来源可复用 | 选已读取视频直接复用；重新输入链接时仅在当前音轨身份/哈希匹配后复用识别 | 不重复识别相同音轨，不把旧包冒充当前新识别 |
| 模型或来源操作失败、状态未知 | 保存原失败与操作身份，按已知可恢复事实处理 | 真实结果明确；未知不自动重放 |

这些判断由产品执行，用户不必选择图型、工具或专业分类。原始请求和明确格式要求始终优先。现有模型策略文件为 `skills/task-solution/SKILL.md`；确定性检查只保证其实际能检查的结构、身份、资源和围栏，不能签署内容正确性。

修复不是无条件增加一道模型审查。只有具体可判别缺陷才安排相应检查；已证明无收益的默认全文编辑不恢复。文案/色彩偏好与影响任务的事实、遗漏或执行前提分别处理。
