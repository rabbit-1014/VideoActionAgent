使用步骤与两次授权

  1. 第 1 步 · 提取视频内容：提交明确的B站视频链接与分P；第一次授权只允许本机匿名下载该分P音轨并在本机语音识别，得到可复用的母版转写。不上传音频，不调用生成模型。
  2. 第 2 步 · 选择需要的成果：选择一份已保存的母版与成果用途（学习笔记、方法清单或母版问答）；第二次授权才允许把这份母版的识别文字发送给已配置模型。页面不会自动发起生成，也不会替你推断想要什么成果。
  3. 第 3 步 · 查看或再次使用：在成果历史中打开已保存的成果阅读或下载；也可以把成果对应的母版再次选为加工来源，由你明确发起新的加工。

两次授权相互独立、互不继承：允许提取音轨并识别，不等于允许把文字交给生成模型；允许加工，也不会重新下载音轨或重新识别。每次生成都需要当次明确勾选许可。

快捷入口 · 链接直接生成成果

当你要“把这个链接整理成笔记/方法/回答”时，在这里一次提交：本机先提取该链接指定分P的音轨并在本机识别（音频不上传），提取成功后自动把识别文字发送给已配置模型，生成所选成果候选。识别与生成都可能失败；两项许可相互独立，都需要当次明确勾选。只想先提取不生成时，请使用下方第 1 步。
